# NHS A&E Breach Rate Analysis - UK 2024/2025
##Problem                                                                                                                                                          Analysis of NHS England A&E Performance data to calculate the 4-hour breach rate for Type 1(Major) departments by Trust.
## Dataset Source: NHS England  A&E Attendances & Emergency Admissions - NHS official website                                                                          Link:https://www.england.nhs.uk/statistics/statistical-work-areas/ae-waiting-times-and-activity/ae-attendances-and-emergency-admissions-2024-25/
##What i did                                                                                                                                                           -Calculated Breach Rate using '=IFERROR(Breaches/Attendances,0)' to handle missing data                                                                               -Created new field:'Breach _Rate' and formatted as percentage                                                                                                         - Ranked Trusts from highest to Lowest breach rate using Paste values to preserve results                                                                                                                                                                                                       
##Files                                                                                                                                                             -`Raw data with Breach_Rate column`- Original NHS England workbook which i added Breach_Rate calculation                                                              -`Ranked_Breach_Rate_Clean.csv` - Cleaned dataset: Name,Breach_Rate(decimal),Rank                                                                                       -`queries.sql` - SQL queries for analysis                                                                                                                                                                                                                                                                                                                                                                                                       
## Methodology                                                                                                                                                               **Breach_Rate=(Type 1 Departments-Major A&E>4hours)/Type 1 Attendances)**                                                                                       Cleaned in Excel:removed % formatting to decimal(0.40),ranked Trusts,exported as CSV for SQL analysis
##Key Queries                                                                                                                                                          1.Top 10 Trusts by breach rate                                                                                                                                        2.National average breach rate                                                                                                                                        3.Count of Trusts with>50% breach rate                                                                                                                                4.![Top 10 Chart ]                                                                                                                                                      (top10_chart.png)
