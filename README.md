# NHS A&E Waiting Times Analysis - UK 2024/2025
##Problem                                                                                                                                                          NHS Trusts are struggling to meet the 4-hour A&E target.I wanted to understand which regions and months have the longest waits.
## Dataset Source: NHS England  A&E Attendances & Emergency Admissions - NHS official website                                                                          Link:https://www.england.nhs.uk/statistics/statistical-work-areas/ae-waiting-times-and-activity/ae-attendances-and-emergency-admissions-2024-25/
##What i did                                                                                                                                                           -Cleaned raw data in Excel -removed duplicates,fixed dates                                                                                                            -Calculated Breach Rate using '=IFERROR(Breaches/Attendances,0)' to handle missing data                                                                               -Created new field:'Breach _Rate' and formatted as percentage                                                                                                         - Ranked Trusts from highest to Lowest breach rate using Pate values to preserve results                                                                              - Identified top 3 worst -performing Trusts                                                                                                                          
##Tools Used                                                                                                                                                           -Excel(Data cleaning,IFERROR,ranking)                                                                                                                                 -SQL(My SQL-Average wait time by Trust and Region)                                                                                                                    -Tableau Public(Visualization)
##Key Findings                                                                                                                                                          Top 3 Trusts with the highest 4 hour breach rates:                                                                                                                    1.United Lincolnshire Hospitals NHS Trust                                                                                                                             2.University Hospitals Plymouth NHS Trust                                                                                                                             3.North Middlesex University Hospital NHS Trust                                                                                                                        These Trusts are driving the worst 4 hour performance in the dataset
