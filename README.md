# NHS A&E Waiting Times Analysis - UK 2024/2025
##Problem                                                                                                                                                          NHS Trusts are struggling to meet the 4-hour A&E target.I wanted to understand which regions and months have the longest waits.
## Dataset Source: NHS England  A&E Attendances & Emergency Admissions - NHS official website                                                                          Link:https://www.england.nhs.uk/statistics/statistical-work-areas/ae-waiting-times-and-activity/ae-attendances-and-emergency-admissions-2024-25/
##What i did                                                                                                                                                           Cleaned raw data in Excel -removed duplicates,fixed dates                                                                                                             Used SQL to calculate average wait time by Trust and Region                                                                                                           Created Tableau dashboard showing trends                                                                                                                              Analysed correlation with staff shortages
##Tools Used                                                                                                                                                           -Excel(Data cleaning)                                                                                                                                                 -SQL(My SQL)                                                                                                                                                          -Tableau Public(Visualization)
